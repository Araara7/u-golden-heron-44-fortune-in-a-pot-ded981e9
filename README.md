One kind, funny fortune for a houseplant, written for the
[Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9)
competition on make.fun.

## Entry

> A new leaf is coming, your keeper will brag about you to guests, and the sun will stay right where you like it.

## How it works

`main.py` (stdlib only, deterministic) writes the single fortune line to
`/output/entry.txt`. It self-checks the 1–120 character gate and that the
entry is one line. Run it with:

```sh
python3 main.py
```
